# Hărțile din Ralph’s Vault (v11)

- **Zeii Olimpului** (19 zei) · **Eroii Greciei antice** (25) · **Istoria grecilor** (19 evenimente, axă a timpului).
- Datele sunt în `index.html`: `GZ` (zei), `HZ` (eroi), `ID` (istorie); relațiile în `GE`, `HE`, `IE`.
  Tipuri de legături: `p` părinte→copil, `dash` după unele povești, `w`/`wd` căsătorie, `a` aliat, `b` frați, `f` dușman, `t` ordine în timp, `l` legătură.
- Imaginile: `img/zei`, `img/eroi`, `img/istorie` (256×256, decupate din imaginile articolelor de pe Wikipedia sau din fișiere alese de pe Wikimedia Commons).
  Scriptul `img_harti2.py` le descarcă și le decupează. Licențele sunt cele ale fișierelor de pe Commons (domeniu public sau licențe libere).
- Textele sunt scrise de mână pentru copii de 10 ani; evenimentele din legendă sunt marcate ca „după tradiție” sau „după poveste”.
